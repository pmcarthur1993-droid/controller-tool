# Controller Tool Suite 2026 (PSTPDT)

Single-file HTML tool for operations-controller work: 15SA, BCA Replan and Reassign Email generation, with the Tail Locator (https://tail-locator.onrender.com) used to auto-fill aircraft location.

- `index.html` — the tool (open directly in a browser, or serve it; no backend needed)
- `Controller_Tool_PSTPDT_v10.html` — same file under its versioned name

Hosted copy: https://controller-tool.onrender.com

Everything runs in the browser; nothing is sent to a server except lookups to the Tail Locator service when you use the location auto-fill.
